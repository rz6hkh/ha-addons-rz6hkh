# AmneziaWG client

Клиент туннеля **AmneziaWG 3.1** для Home Assistant OS. HA подключается к вашему
серверу AmneziaWG (например, на VPS) и становится доступен по адресу внутри
туннеля. Работает в пространстве пользователя (`amneziawg-go`): модуль ядра
в HA OS не нужен.

Неофициальный аддон, не связан с Amnezia и WireGuard.

## Как это устроено

- Аддон работает в сети хоста (`host_network`), поэтому интерфейс туннеля
  появляется у самой системы, и Home Assistant отвечает на адресе в туннеле.
- **Приватный ключ создаётся внутри аддона** при первом запуске и хранится в
  его `/data`. Наружу он не уходит; в журнал выводится только **публичный**
  ключ — его и нужно отдать администратору сервера.
- Конфиг собирается при каждом старте из настроек аддона и живёт только внутри
  контейнера. Секреты (приватный ключ, `preshared_key`, `header_protection_key`)
  в журнал не попадают: вывод `awg-quick` проходит через маску.
- Аддон **отказывается стартовать**, если интерфейс с таким именем уже есть на
  хосте или туда уже есть маршрут к сетям из `allowed_ips`. Так он не перебьёт
  чужой туннель.

## Настройка

```yaml
interface: awg0
address:
  - 10.0.0.3/32
obfuscation:
  - Jc = 4
  - Jmin = 40
  - Jmax = 70
  # ...остальные строки от администратора сервера (S1–S4, H1–H4, I1–I5 и т. д.)
peer:
  public_key: <публичный ключ сервера>
  preshared_key: <PSK, если есть>
  endpoint: vpn.example.com:51820
  allowed_ips:
    - 10.0.0.0/24
  persistent_keepalive: 25
restart_if_no_handshake_min: 0
```

- `obfuscation` — по одной строке на параметр, ровно как выдал сервер. Ключи
  сверяются со списком параметров `amneziawg-tools` 3.1; неизвестный ключ
  остановит аддон с ошибкой, а не попадёт в конфиг.
- `header_protection_key` — отдельное поле-пароль, если сервер его выдал.
- DNS аддон не настраивает: системный DNS хоста не меняется.
- Не указывайте в `allowed_ips` весь интернет (`0.0.0.0/0`), если не хотите
  пустить через туннель весь трафик сервера HA.

## Первый запуск

1. Заполните настройки сервера (`peer`), адрес и параметры маскировки.
2. Запустите аддон, откройте **Журнал** и скопируйте строку
   `Public key of this client`.
3. Передайте публичный ключ администратору сервера.
4. Когда сервер добавит ключ, в журнале появится `Peer: handshake ok`.

Включите **Watchdog** — Supervisor перезапустит аддон, если туннель упадёт.

## Бэкапы

Аддон входит в бэкап Home Assistant вместе с приватным ключом и настройками
(включая `preshared_key`). **Шифруйте бэкапы**, если храните их вне сервера,
или исключите аддон из внешних копий.
